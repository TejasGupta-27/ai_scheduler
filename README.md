# AI Scheduler with Reinforcement Learning

## AI Scheduler is a Rust-based application designed to optimize system process scheduling using reinforcement learning. It leverages a Q-Learning agent to make intelligent scheduling decisions based on real-time system metrics like CPU usage, memory utilization, and process load. The scheduler dynamically adapts to changing system conditions, aiming to improve resource efficiency and throughput.

# Key Features

## Reinforcement Learning: Utilizes a Q-Learning algorithm to optimize process scheduling over time.
## Real-Time Monitoring: Collects and analyzes system metrics, including CPU and memory usage, using the sysinfo crate.
## Dynamic Action Execution: Adjusts system resources and process priorities based on the agent’s decisions.
## Modular Design: Easy to extend or customize for specific requirements.
## This project demonstrates how AI and reinforcement learning can be applied to solve complex system-level problems, offering a foundation for further research and development in resource management and scheduling.
